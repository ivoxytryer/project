# Как запустить study-tracker

Проект: `C:\Users\n\study-tracker` (Vite + React + Tailwind).
Нужны Node.js 18+ и npm (проверено на Node 24 / npm 11).

## Первый запуск (или после смены зависимостей)

```powershell
cd C:\Users\n\study-tracker
npm install
npm run dev
```

Открыть: http://localhost:5173/

## Обычный запуск (зависимости уже стоят)

```powershell
cd C:\Users\n\study-tracker
npm run dev
```

## Остальные команды

| Команда | Что делает |
|---|---|
| `npm run dev` | dev-сервер с автообновлением (http://localhost:5173) |
| `npm run build` | проверка типов + сборка в папку `dist/` |
| `npm run preview` | посмотреть готовую сборку из `dist/` (http://localhost:4173) |

## Облачный режим (Supabase)

По умолчанию приложение работает локально. Чтобы задачи синхронизировались между ПК и
телефоном, подключите Supabase — пошагово в [`SUPABASE.md`](SUPABASE.md). Кратко:

```powershell
copy .env.example .env.local
# впишите VITE_SUPABASE_URL и VITE_SUPABASE_ANON_KEY из Supabase
npm run dev
```

После этого появится вход по email-ссылке, а текущие задачи один раз перенесутся в облако.

## Полезно знать

- Порт 5173 занят? Vite возьмёт следующий свободный — смотри строку `Local:` в консоли.
- Другой порт вручную: `npm run dev -- --port 3000`
- Доступ с телефона в той же сети: `npm run dev -- --host`
- Остановить сервер: `Ctrl + C` в окне терминала.

## Если что-то не работает

- Ошибка про отсутствующие модули → `npm install`
- Странное поведение после смены ветки/зависимостей → удалить `node_modules` и `npm install` заново
- Ошибка `vite не найден` / `npm не распознан` → переустановить Node.js (https://nodejs.org)
