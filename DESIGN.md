# Design System — Study Tracker

Мир: **night ledger** — тёмный рабочий журнал, а не дашборд из стеклянных карточек.
Поверхность Operate: задача пользователя важнее самовыражения, характер живёт
в типографике, плотности и одном сигнатурном приёме.

## Principles

1. Один день — один лист. Главный экран отвечает на вопрос «что сегодня».
2. Действие в один тап: добавить, отметить, перенести.
3. Прогресс без давления: цифры точные, но не кричат.
4. Один интерфейс для телефона и ПК.
5. Тихо, но не безлико: монохром, хайрлайны, мономарки.

## Color

Палитра намеренно монохромная: цвет не несёт смысла, кроме ошибки.

| Токен | Значение | Где |
|---|---|---|
| `ink` | `#0b0c0d` | фон приложения и полей |
| `panel` | `#121315` | hover строк, меню, активный пункт навигации |
| `panel-strong` | `#191a1c` | редкие вложенные поверхности |
| `line` | `#26272a` | хайрлайны, разделители, трек прогресса |
| `line-strong` | `#3a3b3f` | границы чекбокса, зачёркивание |
| `bone` | `#e9e7e1` | основной текст, активные состояния, заливка кнопок |
| `muted` | `#a8a69f` | вторичный текст, подписи |
| `faint` | `#8a8882` | номера строк, плейсхолдеры, метаданные |
| `danger` | `#cf6a5a` | только ошибки и удаление |

Правила:
- никаких градиентов, стекла, `backdrop-blur`, цветных свечений;
- цветной акцент запрещён; состояние выражается яркостью, линией и зачёркиванием;
- контраст основного текста ≥ 7:1, вторичного ≥ 4.5:1.

## Typography

- UI: системный гротеск (`Segoe UI Variable`, `Segoe UI`, system-ui).
- Данные: моноширинный (`ui-monospace`, `Cascadia Mono`) — даты, счётчики, подписи
  разделов, номера строк, легенда.
- Заголовки страниц: 30/36 px, вес 600, tracking `-0.01em`.
- Тело: 15 px; подписи: 10–11 px, uppercase, tracking `0.14–0.18em`.
- Числа всегда `tabular-nums`.

## Layout

- Контент: `max-width: 1024px`, отступы 16 px на мобильном, 24 px на `sm+`.
- Сайдбар: 240 px, скрыт ниже `md`; нижняя навигация на мобильном.
- Правая рейка активности: 176 px, только `lg+`.
- Сетка дашборда: 2 колонки на мобильном, 4 на `lg`, разделители — 1 px через
  `gap-px` на фоне `line`.
- Никаких карточек с радиусом; группировка — хайрлайнами и отступами.

## Components

**Навигация.** Плоские пункты, активный — фон `panel` + `bone`. Никаких пилюль.
Мобильная нижняя панель: 1 px линия над активным пунктом, подписи uppercase.

**Строка задачи.** Номер `01…` моно 12 px, по центру колонки 24 px; чекбокс 18×18
с зоной 44×44; заголовок 15 px; действия. Разделитель — `border-b line`.
Hover — фон `panel`. Выполненная: чекбокс залит `bone`, текст `faint` + `line-through`.

**Прогресс.** Линия 2 px: трек `line`, заполнение `bone`, ширина = процент.

**Дашборд.** Таблица-реестр: подпись слева, значение справа, хайрлайн между
строками. Четыре метрики не в карточках. Заголовок содержит вычисляемую строку
«журнал с … · N дней».

**Heatmap.** CSS-grid, 7 строк, квадратные клетки, заполняет ширину.
Монохромный ramp: `#1c1d22 → #e9e7e1`. 17 недель на мобильном,
52 недели (год) на `lg+`; в узкой рейке — 12 недель с подписями месяцев сверху
(моно 8 px). Подписи месяцев и дней — моно 9–10 px.
`role="img"` и aria-label со сводкой.

**Кнопки.** Primary — фон `bone`, текст `ink`, uppercase 10 px; hover — opacity 80.
Secondary/иконки — прозрачные, hover `panel`. Радиус 0.

**Поля.** Фон `ink`, граница 1 px `line`, фокус — граница `bone`.
Высота 44 px на мобильном, 36 px на десктопе.

**Ошибки.** Баннер/сообщение: граница `danger`, текст `danger`, без заливки.
`role="alert"` у формы.

**Вход.** Обложка журнала: логотип-квадрат с галочкой, моно-подзаголовок,
панель в хайрлайне, две вкладки с костяной линией под активной.

## States

- hover: фон `panel`, без изменения геометрии;
- focus-visible: outline 1 px `bone`, offset 2 px;
- disabled: opacity 30–40, без смены цвета;
- empty: рамка + моно-подпись, без иллюстраций и эмодзи;
- loading: пульсирующий квадрат `bone` + моно-текст;
- error: `danger` + текст восстановления.

## Motion

- **Дождь:** фиксированный слой из 46 мягких размытых капель, наклон 9°,
  отрицательные задержки — дождь уже распределён при загрузке. Не перехватывает
  клики, не влияет на разметку.
- **Появление:** строки задач и секции дашборда — `rise` 420 ms с шагом 24 ms;
  меню действий — `pop` 140 ms.
- **Прогресс:** ширина линии 320 ms `cubic-bezier(.2,.7,.2,1)`.
- **Чекбокс:** галочка масштабируется 150 ms.
- **Выполнение:** строка на 1200 ms заливается тёплым костяным светом
  (отдельный слой, `opacity 0 → .13 → 0`), затем возвращается к обычному виду.
- **Перенос строки:** выполненная задача переезжает вниз через View Transition,
  280 ms; без поддержки API — мгновенно.
- `prefers-reduced-motion` отключает переходы и скрывает дождь.

## Accessibility

- зоны нажатия: чекбокс и кнопки навигации ≥ 44×44 на мобильном;
- клавиатура: все действия доступны, меню «⋯» раскрывается кнопкой;
- скрытые на десктопе действия появляются на hover и `focus-within`;
- контраст проверен, текст не мельче 10 px (только метки), 15 px — тело.

## Don't

- градиенты, `backdrop-blur`, тени, светящиеся акценты;
- скруглённые карточки и «пилюли»;
- эмодзи вместо иконок;
- цветной акцент, кроме семантической ошибки;
- hero-метрики и карточки с иконкой + заголовком + текстом;
- kicker/eyebrow над заголовком.
